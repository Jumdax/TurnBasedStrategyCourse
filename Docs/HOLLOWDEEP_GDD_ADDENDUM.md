# HOLLOWDEEP GDD Addendum

This document supplements `Docs/HOLLOWDEEP_GDD.pdf` with implementation-level rules for procedural/generated content. It does not replace or revise the GDD; it makes explicit a rule the GDD implies but does not state outright, so generated content has a concrete, citable standard to satisfy.

## Room Generation Rules

**Room Accessibility Rule:** Every generated room must allow the party to reach every door, enemy, and chest from the room entrance using traversable grid spaces.
